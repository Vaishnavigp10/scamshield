How the pipeline works

Every report is an event that flows through independent cloud stages.

📥

1 · Ingest

Web form or public API receives the report; PII is redacted and a fingerprint is created.

📨

2 · Event queue

report.received is published to the event bus (Amazon SQS-ready).

🧠

3 · AI classify

TF-IDF + Logistic Regression model fused with explainable URL & urgency rules.

📊

4 · Trends & API

Verdicts are stored, clustered into campaigns, and exposed via dashboard and REST API.
